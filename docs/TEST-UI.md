# 桌面端人工验收清单

启动（带控制台，方便看日志）：

```
E:/software/miniforge/python.exe d:/project/notion_plugin/app/main.py
```

退出：`Ctrl+Alt+Q`

---

## A. 窗口呈现

- [ ] **A1 半透明 / 亚克力**
  背后应是**模糊**的桌面或窗口，不是纯黑、不是纯色块；圆角外侧能看到桌面。
  *失败特征：整体发黑、边缘一圈硬黑边。*
- [ ] **A2 置顶**
  打开浏览器或资源管理器，窗口盖住面板位置 → 面板仍应压在最上层。
- [ ] **A3 位置与缩放**
  面板贴屏幕右侧（右边距约 80px）、垂直居中；文字清晰不发虚，没有被裁切。
  *注意：系统缩放 175% 时窗口物理尺寸约 780×1200。*

## B. 交互

- [ ] **B1 全局热键**
  焦点在别的应用（浏览器/编辑器）时按 `Ctrl+Alt+Space` → 面板浮现并拿到焦点；再按一次 → 收起。
- [ ] **B2 失焦自动收起**
  面板显示时点其他窗口 → 1~2 秒内自动收起；再按热键能正常唤出。
- [ ] **B3 轨道切换**
  点「截止」或按 `→` → 卡片换成截止日期那组；按 `←` 回到「安排」。
  **切换时时间轴位置不应跳动**（看的还是同一时刻）。
- [ ] **B4 关闭与跳转**
  点右上角 `×` → 面板收起；
  双击任意任务卡 → 默认浏览器打开对应 Notion 页面。
- [ ] **B5 中文输入法**
  在「＋ 明天 15:00 交作业」里用输入法打中文：候选框贴着光标、回车不吞字、不闪退。

## C. 系统集成

- [ ] **C1 多显示器（如你有副屏）**
  把窗口拖到副屏 → 位置、大小、模糊是否正常。
- [ ] **C2 开机自启（待你批准后再测）**
  写入 `HKCU\...\Run` 后注销重登，应用是否自动启动并驻留托盘区。

## D. 写入（只动 Notion，不碰本地缓存）

> 默认写正式库。要安全测试，先用测试库启动：
>
> ```powershell
> $env:NOTION_DATA_SOURCE_ID="faa123f9-4216-4f67-be07-ce63ab9222df"
> cd D:\project\notion_plugin; E:\software\miniforge\python.exe app\main.py --keep-open
> ```

- [ ] **D1 快速新增**
  输入「明天 15:00 交作业」→ 回车 → 卡片出现在「截止」轨明天 15:00 处；Notion 里能看到这条。
  只写「买菜」→ 卡片落在今天、显示「全天」。
- [ ] **D2 右键换状态**
  右键任意卡片 → 切换状态 → 圆点变色（未开始 → 进行中 → 已完成），Notion 里同步。
- [ ] **D3 右键删除**
  右键卡片 → 删除 → 确认 → 卡片消失；Notion 回收站里能看到它。

## 我这边后台会验的（不用你管）

- Notion API：创建 / 改期 / 改状态 / 删除，时间往返，404/429 错误处理
- 本地缓存回退：断网、token 失效时是否还能出数据
- 无头渲染：轨道切换、计数、卡片坐标、待安排抽屉、设置浮层
- 启动耗时、常驻内存、隐藏前后内存差
- 自启注册表读写（只读回验证，不重启）
- 日志里有无异常堆栈
