# 桌面端人工验收清单

启动（带控制台，方便看日志）：

```
E:/software/miniforge/python.exe d:/project/notion_plugin/app/main.py
```

退出：`Ctrl+Alt+Q`

---

## A. 窗口呈现

- [ ] **A1 半透明 / 亚克力**
  *2026-10-24 正式入口复核：`transparency -> BackColor=Black, backdrop hr=0/0`；
  窗口 1779,0,2560,1600；面板中心 luma 21.1（透出真实壁纸，不是纯黑）；四角非黑块。
  之前"整块发灰"的根因是 WinForms Form 的 #F0F0F0 底色挡住合成层，已在 enable_transparency 修掉。*
  背后应是**模糊**的桌面或窗口，不是纯黑、不是纯色块；面板是**直角**，四角没有黑块。
  *失败特征：整体发黑（亚克力 tint 太重）、边缘一圈硬黑边、四角有圆角留下的黑三角。*
  *要更暗：把「面板透明度」调高；要更透：调低。*
- [ ] **A2 置顶**
  打开浏览器或资源管理器，窗口盖住面板位置 → 面板仍应压在最上层。
- [ ] **A3 位置与缩放**
  面板**右侧贴边、上下贴边**（整屏高，会盖住任务栏那一行）；文字清晰不发虚、没有被裁切。
  *注意：系统缩放 175% 时窗口物理尺寸约 781×1600；实测 GetWindowRect = (1779,0,2560,1600)。*

## B. 交互

- [ ] **B1 全局热键**
  焦点在别的应用（浏览器/编辑器）时按 `Ctrl+Alt+Space` → 面板浮现并拿到焦点；再按一次 → 收起。
- [ ] **B2 失焦自动收起**
  面板显示时点其他窗口 → 1~2 秒内自动收起；再按热键能正常唤出。
- [ ] **B3 轨道切换**
  点「截止」或按 `→` → 卡片换成截止日期那组；按 `←` 回到「安排」。
  **切换时时间轴位置不应跳动**（看的还是同一时刻）。
- [ ] **B4 关闭与跳转**
  点右上角 `×` → 面板收起；
  双击任意任务卡 → 默认浏览器打开对应 Notion 页面。
- [ ] **B5 中文输入法**
  在「＋ 明天 15:00 交作业」里用输入法打中文：候选框贴着光标、回车不吞字、不闪退。
- [ ] **B6 拖动窗口**
  按住顶栏空白处（日期文字周围）拖动 → 整个窗口跟着走；松手停在原处。
  点齿轮/刷新/×/输入框**不会**拖动窗口。

## E. 设置项生效

设置浮层右上角齿轮打开。所有项都落在 `app/config.json`，重启后应保持。

- [ ] **E1 透明度**
  拖「面板透明度」滑杆 → 松手后背景**立刻**变透明/变实（不是等重启）；关掉应用再开，滑杆与新值保持。
  背后仍是模糊，不是纯黑。
  *失败特征：松手没反应（evaluate_js 没跑）/ 重启回 66。*
- [ ] **E2 主题**
  点「浅色」→ 面板底色变浅、文字反色，布局与卡片位置**完全不变**；点「深色」恢复。重启保持。
  *失败特征：只有按钮变色、面板还是深色（body 上没挂 theme-light）。*
- [ ] **E3 开机自启**
  打开开关 → `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 出现 `TimelineHUD`；
  关掉 → 该项消失。注册表写入失败时应弹「开机自启设置失败」且开关**弹回原位**。
  *（C2 的注销重登验证仍需你批准后再做。）*
- [ ] **E4 隐藏后释放内存**
  开着（15 分钟）：唤出→隐藏，等 15 分钟后进程工作集（任务管理器「内存」）明显下降；
  中途唤出会取消计时。关掉后隐藏不再修剪。
  *判据：同一次会话内，隐藏前 vs 修剪后的工作集差 ≥ 30MB。*
- [ ] **E5 快捷键被占用**
  先用别的程序占住 `Ctrl+Alt+F9`，再把 `config.json` 的 `hotkey` 改成 `Ctrl+Alt+F9` 重启 →
  控制台出现「热键 Ctrl+Alt+F9 注册失败」+「已回落到 Ctrl+Alt+Space」，
  旧组合仍能唤出（配置文件保持你写的新值，改回来重启即恢复）。
  *运行时用 `api.set_config({hotkey})` 改键失败则不会落盘、旧键继续有效（暂无 UI 入口）。*
- [ ] **E6 配置损坏**
  把 `app/config.json` 写成 `{ bad json` → 启动不崩、全部回默认值，坏文件被改名成 `config.json.bad`。

## F. 拖拽改期（只改当前轨道，不做跨轨道拖动）

- [ ] **F1 有时间卡片**
  在「截止」轨按住一张带时间的卡片上下拖 → 出现时间气泡（形如 `10-25 15:30`）→
  松手后卡片停在新位置，Notion 里时间按 **15 分钟**吸附变化；拖动不足 4px 视为点击、不写；
  跨零点时日期跟着进位。
- [ ] **F2 全天卡片**
  全天卡片按**整天**吸附：拖满 336px（= 1 天 = 1440 分钟）进/退一天，
  半天（约 168px）以上也算一天，不足半天回弹；日期变了时间仍是「全天」。
- [ ] **F3 失败回弹**
  断开网络（或把 `NOTION_DATA_SOURCE_ID` 指到不存在的库）后拖动 →
  卡片弹回原位并弹「改期失败：...」，界面不应留下错位或重复卡片。
- [ ] **F4 不串轨道**
  在「安排」轨把卡片往下拖 1 天 → 切到「截止」轨，确认截止日期**没变**；反之亦然。
- [ ] **F5 拖完不误触**
  拖动结束那一下不应选中卡片（`.chip.sel` 不出现），也不应打开 Notion 页面。

## G. 时间轴密度（px/hour，6~40）

- [ ] **G1 Ctrl + 滚轮**
  指针停在时间线上，滚轮向上 = 变密（每档 ×1.15，取整到 0.5），向下 = 变疏；
  **网页本身不能缩放**（面板宽度、字号都不变），光标下的时刻缩放前后停在同一屏幕 y。
  普通滚轮（不按 Ctrl）仍然只是滚动时间轴。
- [ ] **G2 设置里的默认密度**
  拖动「时间轴密度」滑块 → 时间轴**立即**重排、右侧数值同步（如 `22 px/h`）；
  松手 300ms 后写入 `app/config.json` 的 `timeline_scale`，重启后首帧就是该密度。
- [ ] **G3 隐藏后重置**
  Ctrl+滚轮调到 28 → 热键/失焦收起 → 再唤出，密度回到配置里的默认值，且 now 线居中。
  *判据：`window.__hud.getScale()` 与 `config.json` 里的 `timeline_scale` 一致。*
- [ ] **G4 极端值**
  滚轮一直放大到 40、缩小到 6 就停住；此过程中日分隔线、日期标签、卡片都不重叠错位。

## H. 拖拽滚动 / 双击新建 / 字号

- [ ] **H1 拖拽中滚动**
  按住卡片不放、滚轮滚动 → 时间轴跟着滚，卡片仍贴在指针下（不脱手、目标时间不累积漂移）；
  指针移到时间轴上下 48px 内会**自动滚动**（越贴边越快），移回中间就停。
  拖拽中 Ctrl+滚轮**不改变密度**。
- [ ] **H2 双击空白新建**
  双击时间轴空白处 → 输入框被聚焦，预填该位置的时间（如「明天 15:00 」），光标在末尾；
  回车后任务落在**当前轨道**（安排/截止）。双击卡片仍是打开 Notion 页面，不会填输入框。
- [ ] **H3 字号缩放**
  顶栏 `A−` / `A+` 每步 5%，范围 85%~140%，旁边显示百分比；只改卡片文字与卡片高度，
  **时间轴密度（px/h）不变**；重启后保持。

## I. 详情弹窗 / 键盘 / 搜索 / 刷新

- [ ] **I1 外链按钮**
  鼠标移到卡片上，右上角出现 `↗`；点它直接打开 Notion，**不**弹详情、不选中、不触发拖拽，
  时间轴也不跳动。
- [ ] **I2 详情弹窗**
  *真窗口实测（781×1600，266px 宽弹窗）：日期输入 100px / 时间 58px / 下拉铺满，无裁切无横向溢出，
  弹窗 266×245 完整落在视口内。*
  单击卡片 → 卡片旁弹出小面板（空间不够会翻到左侧或下方，不会全屏）。改标题 / 状态 /
  安排日期 / 截止日期（含全天）/ 大方向 / 学科 → 停手约 0.5 秒自动保存，卡片标题、时间、
  状态、位置同步变化；断网时会提示「保存失败」并把输入框退回原值。
  Esc、点面板外、点「关闭」都能收起；拖拽卡片不会弹窗；双击仍是打开 Notion。
- [ ] **I3 逾期胶囊**
  顶部「逾期 N」变成可点胶囊 → 点击切到截止轨、滚到**最早逾期**那一条并闪一下。
  没有逾期时不可点。
- [ ] **I4 键盘**
  `↑`/`↓` 在当前轨道里移动选中（自动滚进视口），`Enter` 打开详情，`Delete` 删除（带确认），
  `Esc` 关弹窗并清选中；在输入框里打字不会触发这些快捷键。
- [ ] **I5 模糊搜索**
  按 `/` 唤起搜索条，输入即过滤（子串或子序列、英文不分大小写），右侧显示命中条数；
  `Esc` 关闭并恢复全部。过滤后剩余的卡片重新堆叠、不留空位。
- [ ] **I6 刷新**
  点右上刷新 → 重新拉数据并整体重渲染（日刻度、卡片、计数、待安排抽屉都更新），
  图标转圈；失败会弹提示。

## 我这边后台会验的（不用你管）

- Notion API：创建 / 改期 / 改状态 / 删除，时间往返，404/429 错误处理
- 本地缓存回退：断网、token 失效时是否还能出数据
- 无头渲染：轨道切换、计数、卡片坐标、待安排抽屉、设置浮层
- 启动耗时、常驻内存、隐藏前后内存差
- 自启注册表读写（只读回验证，不重启）
- 日志里有无异常堆栈
